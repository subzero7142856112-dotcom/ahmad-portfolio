# CV file

Place the real CV PDF here using exactly this filename:

```
Ahmad-Al-Zawahrah-CV.pdf
```

The **Download CV** buttons in the navigation, about section and footer read the path from
`data/personal.ts` (`cvPath`), so you can rename the file as long as you update that value too.

No placeholder PDF is shipped on purpose — the button will 404 until a real file exists.
